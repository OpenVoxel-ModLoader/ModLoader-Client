# instance/

Per-user data of the OpenVoxel ModLoader client (git-ignored except the READMEs):

| Folder | Content |
|--------|---------|
| `mods/` | client mod JARs (`openvoxel.mod.properties` + a `ClientMod` class) |
| `config/` | `user-config.properties` (options/keys), `skin.png`, `cape.png`, `font.ttf`, `tiles/<seed>.json` |
| `lang/` | extra translations `<code>.json` |
| `resourcepacks/<name>/textures/...` | texture overrides (Options → Textures) |
| `sounds/` | WAV sound pack (see its README) |
| `music/` | WAV playlist (see its README) |
| `logs/` | reserved |
