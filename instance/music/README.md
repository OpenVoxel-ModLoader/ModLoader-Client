# Music

Drop `.wav` files here (16-bit PCM; convert MP3/OGG with ffmpeg: `ffmpeg -i song.mp3 song.wav`).
They play shuffled in the background while in a world with pauses between tracks.
Volume: Options -> Music. Chat: `/music play|next|stop|list|reload`.

Free music/sounds (check each license, CC0 is simplest): https://freesound.org (filter CC0),
https://opengameart.org, https://kenney.nl/assets (CC0 audio packs), https://incompetech.com (CC BY).
